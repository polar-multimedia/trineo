# trineo

Entregables de Polar Multimedia para clientes: cotizaciones, propuestas y presentaciones.

- Cada entregable vive en su propia carpeta (por ejemplo `carnot-corep-2027/`).
- `panel/` muestra quién abrió y descargó cada entregable (acceso solo con la cuenta autorizada).
- `shared/` guarda lo común: seguimiento, configuración de Firebase, logo, fondo y tipografía.
- `cotizaciones.js` registra cada entregable con sus códigos. Los nombres de los destinatarios no se guardan aquí.
